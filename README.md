# 🍲 ポット回収ログ

レコルトの自動調理ポットなど、お小遣いで買った家電の購入金額を「使うたびに300円」のルールで回収していく記録PWA。

## 機能

- 購入金額・1回あたりのお小遣い（デフォルト300円）を設定
- 使うたびに「使った！」ボタンで記録（日付・作ったメニュー・メモ）
- 回収済み金額 / 残り金額 / 達成率を進捗バーで表示、購入金額に達すると「回収完了」バナー表示
- メニュー別の記録回数ランキング（タップで履歴を絞り込み）
- 月ごとにまとめた使用履歴（編集・削除可）
- JSONエクスポート / インポート（バックアップ・機種変更用）
- PWA対応（ホーム画面に追加してオフラインでも使用可）

## データ保存

データは端末のブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません。

## 開発メモ

- 静的ファイルのみ。ビルド不要。`python3 -m http.server --directory pot-okozukai-log` で動作確認できます。
- **ファイルを変更したら `sw.js` の `CACHE` バージョンを上げること**（例: `pot-okozukai-log-v1` → `v2`）。上げないと既存ユーザーに更新が配信されません。
